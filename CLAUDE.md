# NotTahaAli profile — rules for agents

GitHub profile README for NotTahaAli. `README.md` renders on the profile;
`assets/` holds its header, cards and dividers.

- Visual output follows the brand design system: DigitalBrain
  `wiki/Resources/Design System/` and the `@nottahaali/design-system` package
  (NotTahaAli/design-system). No new colours or fonts.
- Draft any visible change for Taha before pushing it.
- Code and build scripts: readable and maintainable over clever or compact.
  Small focused modules, one responsibility per file, split anything past ~300
  lines, no god files. Clear names, comments only for the why.
- Privacy: no phone numbers, private emails, client fees or revenue.
- Never write a version number from memory; look it up.
